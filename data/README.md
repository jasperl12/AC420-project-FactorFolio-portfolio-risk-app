# data folder
Small CSV files the app reads:
- sp100_tickers.csv: S&P 100 tickers, sectors and industries (Step 1)
- sp100_estimates.csv: CAPM and Fama-French estimates from the offline training notebook (Step 1)
- market_scenarios.csv: bear, base and bull market returns (Step 1)
- ff_factors_monthly.csv: monthly Fama-French factors from Ken French's data library (Step 2)

No raw WRDS data is stored in this repo.
